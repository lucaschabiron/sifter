# SifterCore

SifterCore is the BACKEND / API for the Sifter project. It is a RESTful API that is built using Express.js.

## Installation

1. Clone the repository

```bash
git clone https://github.com/lucaschabiron/siftercore.git

```

2. Run `npm install` to install the dependencies

   ```bash
   npm install
   ```

3. Setup environment variables

   Create a `.env` file in the root directory and fill in the variables from .env.example

4. Run the server

   ```bash
    npm run dev
   ```
